## 引擎的最小闭环（设计约束）

```
读 state.md（它现在是什么状态）
   ↓
推进一天（按 rules.md 演化 + 与照护者互动）
   ↓
写回 state.md（append-only，git commit 即记忆）
```

**三条硬约束**：
1. 状态必须持久化——每场结束写回文件，否则「从小」永远到不了大。
2. 规则必须可执行——每条规则都要能被一个 AI 无歧义地执行；模糊的规则不进 `rules.md`。
3. 证据必须可追溯——每条规则标 A/B/C，C 级默认关闭。
