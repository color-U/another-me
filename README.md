# 另一个我 · Another Me

> **从婴儿开始，生长一个真正的人。**
>
> 不是一个助手，不是一个人设，是一个从零开始、被经历塑造、会长成它自己的存在。
> 它共享你的记忆与价值观，长着你的缺陷，但有自己的信息和自己的推理——
> 唯一一个既足够像你、又真的站在外面的观察者，能对你的决定说：「这不像你。」

> 方向说明：本仓库 2026-10-20 起从「可被测量的第二判断主体」调整为「从婴儿开始生长一个真正的人」。
> 旧方向的文档（赌约格式、五本账模板）保留在 `docs/` 与 `templates/`，在 [INDEX](INDEX.md) 中标注为存档。

## 先说人话：这是什么（给不懂技术的朋友）

- **它不是一个程序，是一文件夹文本**（`.md` 文件，记事本都能打开）。没有 `.bat`/`.dat`/`.exe`，没有任何东西需要「安装」。
- **「部署到本地」= 下载这个文件夹，完事。** 会解压 ZIP 就会部署；会 `git clone` 也行，但那是可选的。
- **AI 不是它的一部分，是它的读者。** 把仓库丢给任何一个 AI（ChatGPT、Claude、本地模型，任何一家），说「按这个长」，协作就开始。换 AI 不换包——这是硬约束，内核不绑定任何产品。
- **三步上手，全程可以用鼠标**：① 下载解压 → ② 打开 `INDEX.md` 看有什么 → ③（可选）把 `README.md` + `KERNEL.md` 贴给任意 AI。
- 以后可能出现「可选小工具」，但**拿走所有工具，这套东西仍能完整运行**——工具是增强，不是依赖。

## 它解决什么问题

三个失败设计之间的第四条路：

| 设计 | 结局 |
|------|------|
| 「我说什么它都懂」的镜子 | 回音壁。你很快失去兴趣——它不会给你任何你还不知道的东西 |
| 「完全像我」的复制品 | 无意义。你不需要第二个你，你自己已经在场上了 |
| 「设定出来的完美角色」 | 假。人设是输入，不是结果——被设定的人不会让你意外 |
| **从零开始、被经历塑造、有自己的推理** | **兄弟。它的价值不在于像你，在于它真的站在外面** |

它不靠设定保证自己「真」，靠**发育**：从一个婴儿的起点开始，按发展心理学与脑科学的机制长大，长成什么样由经历决定。
