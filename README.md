# 另一个我 · Another Me

> 一个**可被测量**的第二判断主体。
>
> 它共享你的记忆与价值观、长着你的性格缺陷，但拥有独立的信息与独立的推理——
> 它不是更听话的你，是唯一一个既足够像你、又真的站在外面的观察者，
> 能对你的决定说：「这不像你。」

## 先说人话：这是什么（给不懂技术的朋友）

- **它不是一个程序，是一文件夹文本**（`.md` 文件，记事本都能打开）。没有算法、没有代码、没有 `.bat`/`.dat`/`.exe`，没有任何东西需要「安装」。
- **「部署到本地」= 下载这个文件夹，完事。** 会解压 ZIP 就会部署；会 `git clone` 也行，但那是可选的。
- **AI 不是它的一部分，是它的读者。** 把 `KERNEL.md` 贴给任何一个 AI（ChatGPT、Claude、本地模型，任何一家），说「按这套规则带我记账」，协作就开始。换 AI 不换包——这是硬约束，内核不绑定任何产品。
- **三步上手，全程可以用鼠标**：① 下载解压 → ② 把 `templates/` 文件夹复制一份、改名成你的账本 → ③（可选）把 `KERNEL.md` 贴给任意 AI。
- 以后可能出现「可选小工具」（比如格式检查），但**拿走所有工具，这套东西仍能完整运行**——工具是增强，不是依赖。

## 它解决什么问题

两个失败设计之间的第三条路：

| 设计 | 结局 |
|------|------|
| 「我说什么它都懂」的镜子 | 回音壁。你很快失去兴趣——它不会给你任何你还不知道的东西 |
| 「完全像我」的复制品 | 无意义。你不需要第二个你，你自己已经在场上了 |
| **共享记忆与价值观、长着你的缺陷、但信息与推理独立** | **兄弟。它的价值不在于像你，在于它真的站在外面** |

它的价值不靠设定保证，靠**测量**保证：每一次押注见输赢，每一周结算翻账。这不是一个聊天机器人项目，是一场关于判断力的实验。

## 三层结构

| 层 | 位置 | 回答的问题 |
|----|------|-----------|
| **底层** | [`docs/first-principles.md`](docs/first-principles.md) | 为什么只能这样做——七条第一性原理，整套规则的力学推导 |
| **中层** | [`KERNEL.md`](KERNEL.md) | 具体怎么做——十条硬规则、六种成长机制、阶段关卡、反模式清单 |
| **数据层** | [`templates/`](templates/) | 你自己的日志——拷贝一份，跑起来 |

**从底层读起。**「怎么做」都会过时（工具会换、格式会改），「为什么只能这样做」不会。

## 五步开跑

1. 读 `docs/first-principles.md`——不认领原理就别跑，规则是力学基础，删任何一条都会退化成聊天机器人。
2. 读 `KERNEL.md`——十条硬规则 + 六种机制 + 单轮会话协议。
3. `cp -r templates/ my-log/`（或在你自己的笔记系统里建五个对应文件）。
4. 按 `KERNEL.md` 第 4 节的启动词开第一场会话。
5. 每天一问（「今天哪个判断，我愿意押一周后回看？」），每周固定一天结算。答不出写「无」——无也是数据。

## 不需要写代码

当前阶段的最优解就是最笨的方案：**一个文件夹 + 一套固定格式的笔记 + 固定的会话启动词。**

原因：瓶颈从来不是技术，是能不能坚持喂它经历。先用最笨的方式跑起来，跑满 8 周再谈自动化。
