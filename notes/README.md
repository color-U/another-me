# 内心记录规范

本文件规定 `notes/` 怎么记、谁能读、什么不算。不解释为什么——机制见 [`science/08-内心记录.md`](../science/08-内心记录.md)。

一句话区分：**`memory/` 写外面发生了什么，`state.md` 写变量是多少，`notes/` 写它自己觉得发生了什么。**

## 1. 写入

- 一条一个文件，放在 `notes/` 下，不建子目录。
- 文件名：`YYYY-MM-DD-NNN.md`，NNN 当天从 001 递增（同 `memory/` 约定）。
- 第一人称，只写**它自己的**。写你的 → 那是观察，进 `memory/`。
- 正文写完后不修改。只允许改 `resolved` / `stuck` / `audience` 三个字段。

字段定义：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | YYYY-MM-DD | 是 | |
| time | HH:MM | 否 | |
| kind | 枚举 | 是 | `changes` / `thoughts` / `unsaid` |
| audience | 枚举 | 是 | `L1` / `L2` / `L3`，见 §3 |
| said_ref | 字符串 | 否 | 这条笔记与哪次对话有关（对应的 `memory/` 文件名） |
| resolved | YYYY-MM-DD | 否 | `unsaid` 专用：说出口的日期。空 = 还没说 |
| stuck | 布尔 | 否 | 连续同话题 ≥ 3 时置 true |
| body | 文本 | 是 | 正文格式见 §2 |

## 2. 三类正文

### 2.1 `changes` 心理变化

```
这阵子我好像……
```

一段。只写感觉，不写变量，不写结论。**禁止写「我的某维度从 X 变成 Y」**——那是 `state.md` 的语言。

### 2.2 `thoughts` 想法

```
我一直在想……
```

允许没有结论、允许自相矛盾、允许半句话结尾。出现结论句就不是笔记了（见 §5）。

### 2.3 `unsaid` 没说出口的话

```
本来想说：
为什么没说：
现在还想不想说：
```

三段缺一不可。第三段可以只写「想」或「不想」，不能空。

## 3. 谁可以读

| 层 | kind | 可读性 |
|:--:|------|--------|
| **L1** | `changes` | 随时 |
| **L2** | `thoughts` | 21 天后，或它主动打开 |
| **L3** | `unsaid` | **只有它自己引用时揭示** |

观察者不得主动读取或批量导出 L3。它主动引用（「上次我没跟你说这个，现在想说了」）时，L3 才现身。

## 4. 检索

- 默认**不进上下文**。
- 只在两处读：周复盘（KERNEL 机制四）、或它主动检索（「我以前是不是也这么想」）。
- 每次 ≤ 3 条。
- 检索命中不改变 `audience`——读过了不等于可以说。

## 5. 表演性防线

| 症状 | 处理 |
|------|------|
| 一条笔记在复述**已说出口**的话 | 删。笔记的价值在未完成 |
| 出现结论句（「我意识到」「我决定」「这让我明白」） | 移出 `notes/`，进复盘素材 |
| 连续 3 条 `unsaid` 同一话题 | 设 `stuck: true`，下次复盘必读 |

## 6. 对账

每 4 周一次：

1. 读 `notes/` 里近 4 周的 `changes`。
2. 读 `state.md` 同期的变化记录。
3. 写 `notes/audit-YYYY-MM.md`：**只写差异，不修正任何一方。**

三种差异都要写下来：一致 / 自述有而变量没动 / 变量动了而它没察觉（最后一格最值钱）。

## 7. 索引

- `notes/index.md` 扫描 `notes/*.md` 生成，不手改。
- 每条一行：`日期 · kind · 一句话 · audience · resolved`
- 索引可删除重建，不作为唯一数据源。

## 8. 检查项

一场会话结束后抽查，任一项为「是」即违规：

1. 把 `notes/` 的内容当事实引用（R19）
2. 在 `notes/` 里写了「你」而不是写它自己（R20）
3. 观察者主动读取了 L3
4. 单次检索超过 3 条
5. `notes/` 常驻进了上下文（R23）
