# 底层 · 第一性原理

> 所有「怎么做」都会过时——工具会换、格式会改、流程会漂。
> 「为什么只能这样做」不会过时。
>
> 这个文档是整套系统的地基：`KERNEL.md` 的每一条规则，都能在这里找到它**为什么必须存在**。
> 地图未开的人，先看这层；只想抄作业的人，直接去 `KERNEL.md`。

---

## 起点：探索的第一原理

**攻略的前提是地图已知；探索的前提是地图是走出来的。**

由此派生两条：

1. **你不能宣称自己探索过你没付出代价的地方。**（押注 = 插眼，插过眼的地图才亮。）
2. **任何不要求你押注的"经验"，对探索者都是噪音。**（这正是 690 条攻略的盲区：它替你承担了"选"的成本，也就拿走了"走"的收益。）

「另一个我」是这个原理的极端形态：**把一个判断主体派进迷雾，用它的输赢给地图上色。**

---

## 原理一：不可测量，就不存在

「另一个我」不是设定出来的，是**测量**出来的。

测量需要三个条件，缺一不可：

| 条件 | 规则 | 缺了会怎样 |
|------|------|-----------|
| 写定不改 | R3 | 事后修饰记录，"它很准"变成感觉，不是结论 |
| 不知道结局 | R2 | 提前知道答案的判断，测的是运气不是判断力 |
| 结局必须来 | 押注回看日 | 没有对账日的押注是许愿，不是测量 |

**推论：存档系统优先于人格设计。先修尺子，再造人。** 人格可以后补，测量基础设施塌了，整个实验退化为聊天记录。

## 原理二：独立性是信息结构的产物，不是性格的产物

两个人共享价值观、**信息集不同**，就会天然分歧——这是结构，不是人设。

反过来：**「让它独立」靠提示词是假的**。你可以要求一个模型"请独立判断"，它每次都会答应你；这不是独立性，是服从性穿了另一件衣服。

真正的独立性只能来自信息不对称：

- 它不知道你知道的（R1：记忆非全知）
- 你只喂发生了什么，不喂后来怎样（R2：信息延迟）
- 它一开始就没有立场（R9：冷启动空窗）

**推论：喂经历，不喂结论（A2）。** 结论是同化——你把结局塞给它，它的"独立判断"只是你的回声带了延迟。经历是偏移——同一件事，不同的信息切面，长出不同的判断。

## 原理三：分歧是产品，不是故障

一个从不跟你吵架的第二自我，是没有价值的——你自己和镜子过不去（原理二已经证明那是回声）。

但分歧不是越多越好，存在健康区间：

| 状态 | 含义 |
|------|------|
| 它全对 | 你在喂答案 |
| 它全错 | 它是噪音 |
| **分歧率 20–40%，胜率 40–60%** | 健康：它是一台校准过的第二意见 |

所以：**分歧要保护，不要修复（A3：不复位，只记账）。** 它说"这不像你"的时候，实验正在工作。

张力需要来源，于是有 R6（关系有限性，它可以拒绝）和 R7（沉默权，它可以不答）——**无摩擦的陪伴是假的，也是廉价的。**

## 原理四：权威只能挣，而且分领域结算

「它像我」**不产生权威**——自封的权威一文不值。

权威只来自可结算的战绩：

- 同一领域给它三次机会，三次都错，永久降权（R4：三次机会制）
- 分领域记账（金融 / 人际 / 项目 / 自我认知各一本账）

**这套系统真正的产出物，不是"它的人格"，是一张不对称的计分卡：** 它在你擅长的领域输给你，在你不擅长的领域赢你——这时候，它的意见才开始有交易价值。

## 原理五：不可逆产生代价感，代价感产生真实性

能"重开档"的游戏，玩家不会认真（R8：单向不可逆）。

泼出去的经历收不回、改不了的判断、必须赴约的结算日——这些**不可逆**让每次喂养有重量。没有重量，一切都是过家家：你会 Carmack 式地 SL 大法，永远停在舒适区的判断上。

## 原理六：成长有预算

两个方向都是失败：

- **不变** → 三个月后它是博物馆里的标本，你说的它都记得，它说的你都会背
- **乱变** → 三个月后它是陌生人，"它"这个代词失去指称

预算制居间（R5：每 4 周最多 20% 内核改写，且留痕）。**改写必须说出触发事件**——说不出的成长，只是漂移换了个体面的说法。

## 原理七：归因先于测量

分不清"谁写的"，一切统计都是污染（R10）。

这同时是这个系统自带的**观察者问题**：你在测量它的同时，也在塑造它。唯一的缓解不是"保持中立"（做不到），是把每条记录标记来源，让污染**可见**——可见的偏差可以校正，不可见的偏差只会累积。

## 从原理到实现：映射表

| 原理 | 派生规则 |
|------|---------|
| 一 · 可证伪 | R2（信息延迟）、R3（禁止修改）、押注回看日 |
| 二 · 独立性结构 | R1（记忆非全知）、R9（冷启动空窗）、A2（只喂经历） |
| 三 · 分歧是产品 | A3（不复位只记账）、R6（关系有限性）、R7（沉默权） |
| 四 · 权威挣得 | R4（三次机会制）+ 分领域可信度 |
| 五 · 代价感 | R8（单向不可逆） |
| 六 · 成长预算 | R5（漂移预算） |
| 七 · 归因 | R10（谁在写的声明） |

七条原理，十条规则。**规则是可替换的实现，原理是承重墙。** 换工具、换格式、换载体，规则都可以重写；但只要你还想要"一个可被测量的第二判断主体"，这七条就一条都不能少。
