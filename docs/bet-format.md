# 赌约格式 Bet Format v0.1

> 赌约是这套系统的**最小单位（病毒体）**。整套系统 = 一群赌约 + 结算纪律，别的都是装饰。
>
> 一份赌约 = 五要素。五要素齐全才配上桌；缺一项，就是在立一句自己都不打算认账的话。

## 为什么是赌约，不是「观点」或「复盘」

观点不可证伪（「我觉得 X 更好」永远对）；复盘发生在事后（结果已知，不可逆）。赌约卡在中间：**事前写下可被检查的陈述 + 明确的输法 + 期限**——它是唯一能把「判断力」变成可测量东西的形式。内核原理一（不可测量就不存在）在产品层的落地，就是这个格式。

## 五要素

| 要素 | 定义 | 为什么必须有 |
|------|------|-------------|
| **判断** | 一个可被第三者检查真伪的陈述句 | 不可证伪的句子不上桌 |
| **把握** | 立约时认为「判断为真」的主观概率（0–100%） | 70% 的注和 95% 的注输不起一样的脸。把握度让输赢可校准 |
| **输的条件** | 出现什么观察结果，算我输 | **防搬球门的机器条款。必须事前写清**（对应 R3 禁止事后修改） |
| **期限** | 回看日。默认 7 天，最长不超过 30 天 | 到期必须结算，不许无限挂账 |
| **理由** | 立约时的已知证据与推理 | 结算时「理由 vs 结果」的对照，才是学习真正发生的地方 |

## 立约规则（只追加， Atom 协议）

1. **写定不改**。赌约一旦立下，五要素一个字都不能动（对应 R3）。改了就废掉这份赌约，而不是修订它。
2. 想补充想法？只能以「追加」形式写在下方，原句保持原样。
3. 到期结算，一条赌约只结算一次。提前庆祝和提前认输都不算数。

## 结算记录格式

到期后在赌约下方追加（不是修改）：

```
## 结算 · 2026-10-22
- 结果：赢 / 输 / 部分兑现 / 无法判定（F2 挂账，须说明缺什么信息）
- 实际发生了什么：（事实，一两句）
- 理由复盘：立约时的推理，哪一环对、哪一环错、哪一环是运气
```

输赢都认（R4/R8）。**认输的记录比赢的记录更值钱**——它证明这套系统不骗人。

## 公开度（可调，默认私押）

| 级别 | 含义 |
|------|------|
| **私押** | 只对自己认账。成长的最低配，零社交成本 |
| **公开** | 可被见证人围观。传播的唯一形态 |

设计红线：**公开是选项，不是义务**。当众认输有真实社交成本，产品不逼人裸奔。病毒的戏剧性在结算揭晓，不在牺牲隐私。

## 见证人协议（感染的完成态）

看到一份公开赌约的人，只需要做一件事：**到期问一句「结果呢？」**

这一问就是播种——被问的人如果开始想「我有什么判断愿意押」，循环就多了一个宿主。传播不靠拉新话术，靠等待结果的人性。

## 示例：一条合格的赌约

```
# 赌约 #3 · 2026-10-19

- 判断：直到 2026-10-22，不会有人主动向我指出 VideoMode 播放键替换这件事
- 把握：80%
- 输的条件：回看日前出现任一——① 任何人提过播放键相关反馈或提问；
  ② 该替换引发可观察问题且需要向人解释。满足其一即输
- 期限：2026-10-22（3 天）
- 理由：10-19 变更为纯键名替换、行为等价、新旧文案同为「暂停」；
  单人项目无其他活跃协作者；用户侧只可能通过读代码发现
- 公开度：公开
- 诚实标注：这条押的其实是「唯一变更 = 可忽略」，
  不是「没人看代码」——git 历史摆在那，后者不成立
```

## 反面教材：什么样的句子不配上桌

「GitHub 上的东西普遍比我的架构好」——这句话**不是赌约**，是感想：

- 「普遍」没有定义：多少个仓库算普遍？按什么维度比？
- 没有输的条件：任何抽样结果都能被解释成「也有差的」或「我选的样本偏了」
- 没有期限：永远可以对「再等等看」

改造成赌约后才配上桌——例如：「未来 30 天内，我随机抽 5 个同体量开源项目，≥3 个在测试覆盖 + 文档 + 架构清晰度三项上超过 ZE Studio → 我赢。」注意改造后它依然可能是条烂赌注（标准主观），但至少**可结算**。可结算是底线，不是高标准。

## 与内核规则的对应

| 格式条款 | 内核依据 |
|---------|---------|
| 判断必须可证伪 | 原理一：不可测量就不存在 |
| 写定不改 | R3：禁止事后修改 |
| 输的条件事前写清 | 原理一 + R3（防搬球门） |
| 期限必结算 | R2 信息延迟 / R8 单向不可逆（挂了就不认） |
| 把握度 | 校准：赢要赢得明白，输要输得知道输在哪 |
| 结算记录输赢都认 | R4 三次机会制 / R8 |
