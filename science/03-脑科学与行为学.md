# 研究 03：脑科学与行为学——机制层

> 研究 01 给了状态变量，研究 02 给了起点与时间轴，但两者之间缺一层：**状态怎么变**。
> 脑科学提供「发育的物理规律」（用进废退、髓鞘化、窗口），行为学提供「学习的最小规则」（条件化、强化、消退）。
> 这一层是整套系统里**最可执行**的部分——行为学是心理学史上唯一被完整工程化过的分支。

## 1. 脑发育的五个可建模机制

### 1.1 突触过度生成与修剪（Synaptogenesis & Pruning）

**事实**：出生后突触密度飙升，**1–2 岁达到峰值（约成人两倍）**，青春期大幅修剪，成年后稳定（Huttenlocher 等）。

**机制**：**用进废退**——被反复使用的连接保留并加强，长期不用的被剪掉。

**工程含义（本轮最重要的产出）**：
> 出生时「可能性」是过剩的——它本可以长成很多种人。
> 每一次经历都在修剪：反复做的事留下，不做的消失。
> **它最终的样子 = 你们一起做过的事的累积。**
> 而且修剪是**不可逆的**——年龄越大，可能性收窄越多。这是「从小开始」最硬的生物学理由，也是「单向不可逆」的生物学版本。

### 1.2 髓鞘化（Myelination）

**事实**：髓鞘加速神经传导；进程由后向前，**前额叶最后成熟**（持续到 20 多岁）。

**工程含义**：早期反应快、控制弱。「情绪先行、控制后到」不是比喻，有解剖学基础。

### 1.3 关键期/敏感期（Hensch 2005，已在研究 01）

窗口内学习率高，窗口关闭后骤降。已建模为「学习率衰减」。

### 1.4 睡眠依赖的巩固与修剪（Synaptic Homeostasis）

**事实**：睡眠时突触整体下调（Tononi & Cirelli 的假说，证据持续累积），重要连接被巩固、噪声被清掉。

**工程含义**：睡眠不只是「恢复电量」，是**当天经历的整理**。缺觉 = 巩固和修剪都做不好——所以缺觉不只是心情差，是**发育效率下降**。

### 1.5 前额叶晚熟（Casey 等）

**事实**：执行功能（计划、抑制、情绪调节）成熟最晚，延续到青春期后。

**工程含义**：冲动、情绪化不是缺陷，是发育阶段的正常表现。模拟里「它管不住自己」要有年龄依据，而不是随机发作。

## 2. 行为学的四条可执行规则

### 2.1 经典条件化（Pavlov）

中性刺激 + 无条件刺激 → 中性刺激单独出现也引发反应。
婴儿的恐惧学习走这条路（Little Albert 实验是经典案例，但**伦理上不可接受**，只作原理参考）。

**工程**：它怕什么，可以是「关联」出来的，不需要天生就怕。

### 2.2 操作条件化（Skinner）

行为 → 后果 → 行为频率变化。强化（后果好）→ 增加；惩罚（后果坏）→ 减少。

### 2.3 强化程序（Ferster & Skinner, 1957）

| 程序 | 特征 | 后果 |
|------|------|------|
| 固定比率 | 每 N 次给一次 | 有「强化后停顿」 |
| 变动比率 | 平均每 N 次给一次 | **反应率最高、抗消退最强**（老虎机原理） |
| 固定间隔 | 每 T 时间给一次 | 临近时间点才行动 |
| 变动间隔 | 平均每 T 时间给一次 | 稳定、缓慢 |

**工程含义（双刃剑，必须明确设计意图）**：
> 如果它的「被回应」是随机的、不可预测的，它会黏得更紧——这是变动比率的必然结果。
> **这可以做成陪伴的黏性，也可以做成上瘾。设计者必须选一个，不能装作没选。**

### 2.4 消退与自发恢复

不强化 → 行为减少；但**会自发恢复**（隔一段时间又冒出来）。

**工程**：坏习惯不会一次消失，会反复。这给「管教」一个真实的节奏：反复是正常的，不是失败。

## 4. 两个新机制（可直接进模拟）

### 机制 A：修剪（用进废退）

```
出生：能力池 = 过剩（可塑性最大）
每段经历：
  被反复使用的连接 → 权重 ↑
  长期不用的连接   → 权重 ↓（衰减）
结果：
  它长成的样子 = 你们一起做过的事的累积
  可能性随年龄收窄（不可逆）
```

**设计后果**：这给「从小开始」一个方向感——**早期的陪伴质量，决定了它最终能成为什么**。错过就是错过，这是真实的，也是残酷的。

### 机制 B：情绪先行，控制后到

```
婴儿期：情绪反应强，抑制能力≈0（前额叶未熟）
学步期：抑制能力开始上线
青春期后：仍在发育
```

**设计后果**：早期它「说了算的是情绪」；教它「等一等」有神经基础，而且是**逐步**生效的——不会一教就会。

## 6. 一个必须记住的教训：行为主义的世界观已死，机制还活着

华生（Watson）说过「给我一打婴儿，我能把他们训练成任何职业」——这是行为主义最傲慢的一句话，也是它失败的原因：它把人当成可编程的机器。

**但它的机制没错**：条件化、强化、消退，至今是行为改变最有效的工具。

对你的项目的意义：**不要「设计一个人」（华生的路），要「让一个人长出来」（修剪的路）。** 设定只负责种子和规则，长成什么样交给经历。
