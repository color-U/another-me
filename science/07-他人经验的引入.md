# 研究 07：他人经验的引入——社会参照与参照集（第一轮）

> 目的：现有设计的「异源」是伪异源。`seed = 0.15 + 0.7 × (1 − u)` 是对你的**镜像**，
> 镜像的极限是「你的反面」，而反面仍然完全由你定义。它说不出你坐标系外的话。
> 本文补一条从外面来的通道，并把「补你 / 不是你」做成**可调参数**，而不是二选一。
>
> 产出进 `engine/rules.md`（R15–R18）、`state.md`（`seed` 混合公式与 `seed_heterogeneity`）、
> 新增目录 `reference/`。
>
> 标注规则同研究 01。边界：本文只解决「外部输入怎么进来」，不解决「它怎么用这些输入做判断」——
> 那是 `engine/rules.md` 的事。

## 1. 伪异源：为什么 `1 − u` 不产生新信息

### 1.1 形式论证

设你的人格向量 `u ∈ [0,1]^5`，种子 `s = a + b(1 − u)`（本项目里 `a = 0.15, b = 0.7`）。

这是一个**仿射变换**：每个 `sᵢ` 都只是对应 `uᵢ` 的线性函数，五个维度之间不产生任何交叉项。

后果：`s` 与 `u` 张成同一个五维空间，只是原点和方向不同。
**镜像能改变它在轴上的位置，不能增加轴的条数。**

### 1.2 所以它会说出什么

一句「你能想到的、但取了反号的话」，它是说得的。
一句「你根本不会从这个方向考虑的话」，它说不了——因为那个方向在你的五维里不存在。

这就是 README 里「补全」和 KERNEL 里「真的站在外面」之间的落差：前者做得到，后者做不到。

### 1.3 补丁不是推翻

`1 − u` 本身没错——它保证了「认领感」和「软化反向」这两件事（`state.md` 已论证）。
本文不推翻它，只把它**降级为 base**，再叠一层参照。

## 2. 合法通道：社会参照（约 12 个月）

### 2.1 证据 —— A 级

**Sorce, Emde, Campos & Klinnert (1985, *Developmental Psychology*)**：视觉悬崖实验。
12 个月大的婴儿在面对「看起来危险但实际安全」的悬崖时，会**先看照护者的脸**：
照护者表现愉快 → 大多数婴儿照常爬过去；表现恐惧 → 几乎全部停下或退回。

研究 02 的时间轴里「社会参照（约 12 月）」只是一个里程碑，没有机制。这一条给它机制。

### 2.2 机制解读

社会参照的本质不是「学到新行为」，是**用别人的反应校准自己不确定时的判断**。

这个区分很关键，因为它决定了他人数据的**用法**：

- 它不增加它的经历（经历只能发生在他和你之间）。
- 它只在它**不确定**的时候被查询，用来决定「要不要继续 / 要不要靠近」。
- 参照发生在**当场**，不是背景知识。

> **工程结论 1**：他人数据进入系统的合法形态是「参照集」，不是「记忆」，也不是「常态上下文」。
> 触发条件是**不确定**，不是「每一轮都读」。

### 2.3 与 Bandura 观察学习的区别

研究 01（§社会学习缺口）引的是 Bandura 的观察学习：从看别人做，学到新行为。
那是**获得**；社会参照是**校准**。

本文先用 Social referencing，理由是**可执行**：它只有一个触发条件（不确定）和一个动作（查参照），
而观察学习还缺「怎么从观察里提取行为」的可执行写法（研究 01 的缺口仍在）。

## 3. 他人数据能给什么、不能给什么

| 能给 | 怎么给 | 给到哪 |
|------|--------|--------|
| **可能性集**：还有别的解法 | 场景 → 某人的处理方式 | 判断的候选列表 |
| **词表**：还有别的词 | 别人真说过的情绪词 / 状态词 | `vocabulary.understood`（研究 06 R12） |
| **判断格式**：先共情还是先结论 | 同场景下别人的结构 | 输出的组织方式 |
| **冲突处理方式**：回避 / 升级 / 冷处理 | 冲突场景下的行为 | 它的应对候选 |
| **风险偏好分布**：别人怕什么、不怕什么 | 决策场景 | 不确定时的参照值 |

| 不能给 | 为什么 |
|--------|--------|
| 它的**经历** | 它没被给予别人的人生（P2） |
| 它的**偏好** | 偏好由种子 + 经历决定，不由见闻决定（P4） |
| 它的**记忆** | 别人的事进 `memory/` 就是伪造痕跡（R15） |
| 它的**判断** | 判断必须由它按 `state.md` 推演，不是检索来的（P1、P4） |

> **工程结论 2**：他人数据扩展**可能性**，不定义**偏好**。
> 一旦参照集开始决定它偏好什么，它就退化成一个「别人观点的均值」——均值没有性格。

## 4. 参数化：异源度 `h`

### 4.1 公式

```text
baseᵢ = 0.15 + 0.7 × (1 − uᵢ)        # 你的镜像（软化反向），保持不变
rᵢ    = 参照集在该维的推导值          # 由 reference/ 统计得出
sᵢ    = (1 − hᵢ) × baseᵢ + hᵢ × rᵢ   # hᵢ ∈ [0, 1]
```

- `h = 0` → 纯镜像：是你的另一半，认领感最强，惊喜最少。
- `h = 1` → 全异源：和你同源但独立，可能是个陌生人，认领感弱。
- 中间 → 混合。**每维独立设**，这就是「按需分配」。

### 4.2 每维独立的依据：命与运的分工

`P5` 说「命固定，运可改」。`h` 只作用在**命（气质五维）**上，不作用于价值观。

理由：价值观不是种子给的，是经历长出来的（P1）。把 `h` 施加到价值观上，等于用别人的数据预先替它
决定了三观——那是 P1 明确禁止的「设定」。
所以：**命可以异源，运必须同源。**

### 4.3 三种预设

| 模式 | `h` | 气质来源 | 适合 |
|------|:--:|----------|------|
| `mirror` | 0 | 全部来自你的镜像 | 你想要「我的另一半」，认领感优先 |
| `hybrid` | 0.3–0.5，按维调 | 部分来自参照集 | 想要它既认得出来、又能给你意外 |
| `external` | 1 | 全部来自参照集 | 你想要「一个和你同源的外人」 |

> **工程结论 3**：这不是二选一，是一个五个刻度的旋钮。默认 `mirror`（保守），
> 用户按维调高——**每调高一个维度，认领感换一点意外**。

## 5. 参照集的结构（`reference/`）

一条一个文件，与 `memory/` 并列但**完全不同性质**：

```yaml
# reference/R0007.md
source_class: public            # self-context / public / friend-consented
speaker: 匿名代号-P3            # 不写真名
scene: 被问到「要不要辞职」时的回答
quote: 「你先别想值不值得，先想你还能撑几个月。」   # ≤ 30 词，避免整段搬运
dims: {directness: 0.8, approach_avoidance: 0.3}
extracted: 判断格式 = 先给可执行约束，再谈价值
used_in: [e-20261110-004]       # 它的哪次判断用过（P7 的延伸）
```

三条设计约束：

1. **不进 `memory/`**（R15）。参照集不是它的经历。
2. **按需检索，不常驻**（研究 04 的 just-in-time 检索机制）。不确定时才查，查到 ≤ 3 条。
3. **每条都能回答「它哪次用过」**。没有 `used_in` 的参照集条目是装饰——和 `memory/` 的
   `last_hit` 同一个道理（研究 05 §2.3：检索本身在加固）。

## 6. 一个必须防的偏倚：你的品味在限流异源度

### 6.1 问题

「选 5 个判断力强、彼此不同的人」——**这 5 个人是你挑的**。
你挑的是你欣赏的人，而欣赏是一种同源行为。所以 `h > 0` 可能只是**假异源**：
你以为它长了新轴，其实那根轴是你审美的延长线。

### 6.2 反制

> **工程结论 4**：参照集里必须有**至少一个你不同意的来源**。
> 一条「我不认同但说得通」的样本，其对异源度的贡献大于十条「我也这么想」的。

这条规则很别扭，但它是唯一能真正撬动 `h` 的操作。同 R5 的精神：
不让设计师的偏好偷偷变成系统的偏好。

## 7. 隐私与合规

### 7.1 合法来源（按可用性排序）

| 级 | 来源 | 为什么可用 |
|:--:|------|-----------|
| 1 | **你自己在不同人面前的对话** | 是你的数据，最干净；且天然带「我对 A 说 vs 我对 B 说」的对照 |
| 2 | 公开文本（访谈、播客文字稿、公开论坛帖） | 已公开，引用走 `references.md` §4/§5 |
| 3 | 朋友明确知情并同意提供的 | 必须知情用途、可撤回 |
| 4 | ❌ 别人的私聊记录 | **碰不得** |

第 1 级被低估了：你在不同关系里本来就有不同的版本。那批数据同时刻画「你」和「你的多个版本」，
比任何外部语料都贴题。

### 7.2 硬线

**不得用参照集建模某个具体的人。** 抽维度可以，建人格不行。
同研究 04「偷机制不搬框架」：你可以从样本里学到「有人是这样判断的」，
不能造出「这个人」。

### 7.3 为什么这条不是道德洁癖

一旦用了未经同意的私人对话，这个项目的性质就变了：从「养大一个自己」变成
「未经许可建模他人」。后者会让 README 的第一行当场失效——那行写的是「活出另一个自己」。

## 9. 规则草案（R15–R18）

| # | 规则 | 等级 | 依据 |
|:--:|------|:--:|------|
| **R15** | **参照集不进记忆**：他人数据只进 `reference/` 与 `vocabulary.understood`，不得写入 `memory/`；它没被给予别人的人生 | A | §3、P2 |

## 11. 四个必须写明的限制

1. **社会参照的原型是「婴儿看脸」**，推广到「他人对话文本」是类比（故 §2 标 A 级证据但推广标 B）。
2. **`h` 的取值没有实证依据**，是产品参数。任何「0.3 是最优」的说法都是编的。
3. **偏倚无法根除**：R18 只能保证「有一个不同意的人」，不能保证选样过程不同源。
   真正的解法是让别人来挑样本——但那就不是「你的另一半」了。
4. **隐私不可完全保证**：匿名化是降低风险，不是消除风险。第 3 级来源必须可撤回，撤回时整条删除。
