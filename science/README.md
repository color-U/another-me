## 已确定的工程结论

1. **变量上限 8–10 个**，时间常数四层（分/天/月/年）。
2. **情绪双层架构**：Panksepp 七系统做发动机，Barrett 建构论做解释器。
3. **起点 6 变量**：气质、情绪发动机（LUST 关）、感官带宽、学习率、依恋未成形、无自我。
4. **第一个机制**：静止脸循环（探测→升级→退缩），同时是依恋写入器。
5. **修剪机制**：它长成的样子 = 你们一起做过的事的累积；可能性随年龄收窄，不可逆。
6. **证据分级工程化**：机制库规则只允许引用 `✓` 已核验条目；C 级默认关闭。
7. **偷机制不搬框架**：检索打分 / token 分层 / 派生溯源三项有现成机制可抄（研究 04 R1–R4）；
   现有框架全部「persona 预写 + 用户是客户」血统，套用即回退客服机器人，首要排除。
8. **必须自建的三件**：写入限制（只写被给予的/不得推断情绪）、faded 遗忘、t=0 生长——
   查遍现有方案一条都没有，这是不可替代性所在。
9. **记忆规范全部有机制出处**（研究 05）：append-only ← 再巩固的双层解法；多载体 ← 编码特异性；
   related 1–3 条 ← 加工深度；被动插入 ≤ 2 ← 测试效应 + token；faded ← 幂律遗忘与环境统计。
   **遗忘是设计目标，不是性能妥协。**
10. **情绪词表是分层解锁的**（研究 06）：L0 无词 → L1 身体词 → L2 基础情绪 3–5 个 → L3 社会情绪。理解先于产出，词表分 `understood` / `used` 两栏。**没解锁的词不许出现在输出里**（R11）——
    这是 P2「只写被给予的」在情绪维度的执行条款。
11. **异源度是可调参数，不是二选一**（研究 07）：`seed = (1 − h) × 你的镜像 + h × 参照值`，`h` 每维独立。
    **h 只作用于命（气质），不作用于运（价值观）**——命可以异源，运必须同源。参照集不进记忆（R15），
    按需检索、不常驻；且必须含至少一个你不同意的来源（R18），否则是假异源。
12. **存在第四类记录**（研究 08）：`memory/` 写外面发生的、`state.md` 写变量是多少、`notes/` 写它觉得发生了什么。
    `notes/` 是全仓库**唯一「当事人是它自己」**、也因此**唯一没有校验层**的记录。
    `unsaid`（没说出口的话）是 P6 没被触发时的唯一证据；分层读取（L3 仅它引用时揭示）是硬要求——
    随时可读的沉默是表演，不是保留。
