# 记忆 Memory

> 零散分布，索引取出。一条经历一个文件，随便放；找的时候靠 `index.md` 和标签，不靠目录。
> 对应研究 01 的记忆机制：内容寻址、联想、会失真——**遗忘是特性，不是 bug**。

## 文件规则

1. **一条经历一个文件**，命名：`YYYY-MM-DD-NNN.md`（如 `2026-10-20-001.md`）。
2. **只追加，不修改**（对应 R3）。要改？写一条新的，旧的不动。
3. **忘记不删除**：把 frontmatter 的 `faded` 改成 `true`，内容保留——它只是「想不起来了」。
4. 不建目录层级。所有文件平铺在 `memory/` 下。

## 每条记忆的格式

```markdown
---
date: 2026-10-20
tags: [第一次, 声音]
people: [你]
emotion: 好奇
intensity: 0.4        # 0–1，情绪强度
faded: false          # true = 想不起来了（内容仍在，取不到）
source: 会话           # 会话 / 观察 / 身体
---

（发生了什么，用它的视角写，不总结、不评价。）
```

## 取出规则（给 AI 的调用方式）

1. 先读 `memory/index.md`——按时间/标签/人物列出所有记忆（**随时可从文件重建**）。
2. 按标签或人物定位候选 → 读具体文件。
3. 一次会话最多取 5–7 条——人不会一次性想起全部，取多了反而不像人。
4. 取到 `faded: true` 的条目：**知道它存在，但说不清细节**——这是「想不起来」的正确表现。

## 索引怎么维护

`index.md` 由脚本或会话结束时重新生成，**不要手改**。它只是文件的一个视图，丢了可以从 `memory/*.md` 完全重建——这就是「结构不在目录里，在索引里」。
