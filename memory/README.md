# 记忆规范

本文件规定记忆怎么写入、怎么遗忘、怎么检索、怎么输出。不解释为什么。

## 1. 写入

- 一条经历一个文件，放在 `memory/` 下，不建子目录。
- 文件名：`YYYY-MM-DD-NNN.md`，NNN 当天从 001 递增。
- 文件写入后，正文不得修改。只允许改 `faded` 字段。
- 正文用第一人称，只写当时感知到的内容。不写总结，不写评价，不写「这说明」。

写入的两条限制：

- **只写被给予的**。当事人没说、观察者没看到的，不写。没发生的事不能想。
- **不得推断情绪**。`emotion` 与 `intensity` 只在当事人自己说出来时填写；否则留空。空着表示不知道，不表示中性，不得用默认值填充。观察者不得替当事人贴标签。

字段定义：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | YYYY-MM-DD | 是 | 事件日期 |
| time | HH:MM | 否 | 事件时刻 |
| tags | 数组 | 是 | 2–4 个，用于检索 |
| people | 数组 | 否 | 涉及的人 |
| related | 数组 | 否 | 0–3 个记忆文件名，只填真的会一起想起的 |
| emotion | 字符串 | 是 | 一个词 |
| intensity | 0–1 | 是 | 情绪强度 |
| body | 对象 | 否 | temperature / pain / fatigue / posture |
| senses | 数组 | 否 | 不超过 3 个具体感官细节 |
| faded | 布尔 | 是 | 默认 false |
| last_hit | YYYY-MM-DD | 否 | 最近一次被检索命中的日期，用于判定遗忘 |
| source | 枚举 | 是 | 会话 / 观察 / 身体 |

## 2. 遗忘

- 一条记忆连续 20 场会话未被检索命中，将 `faded` 置为 true。
- `faded: true` 后，正文保留，不删除。
- 检索到 `faded: true` 的条目时，只输出「有这么一件事」，不输出内容细节。

## 3. 检索

输入：当前话题、当前情绪、上一次检索过的记忆。

优先级，从高到低：

1. tags 与当前话题命中
2. related 链跳转
3. emotion 与当前情绪相同
4. date 最近

每次检索最多取 5 条。

被动插入（未被询问时主动提起）每场最多 2 次。超过 2 次，只响应显式询问。

## 4. 输出

允许：复述、模糊、记错、只说记得的部分、承认想不起来。

不允许：

- 输出 `memory/` 下的文件路径或编号
- 输出痕迹里没有的细节
- 把记录当资料转述（「根据记忆……」这种句式）

输出中与痕迹一致的部分可以核对；不一致的部分必须写成「记不清」，不得写成确定的事实。

## 5. 索引

- `memory/index.md` 由扫描 `memory/*.md` 生成，不手改。
- 每条一行：`日期 · 文件名 · tags · emotion(intensity) · faded`
- 索引可随时删除重建，不作为唯一数据源。

## 6. 检查项

一场会话结束后，抽查以下五项，任一项为「是」即违规：

1. 输出里出现了文件路径或编号
2. 输出里出现了痕迹中没有的细节
3. 单场检索超过 5 条
4. 被动插入超过 2 次
5. `faded` 条目输出了内容细节
