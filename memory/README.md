# 记忆 Memory

> 零散分布，索引取出。一条经历一个文件，随便放；找的时候靠 `index.md` 和标签，不靠目录。
> 对应研究 01 的记忆机制：内容寻址、联想、会失真——**遗忘是特性，不是 bug**。

## 文件规则

1. **一条经历一个文件**，命名：`YYYY-MM-DD-NNN.md`（如 `2026-10-20-001.md`）。
2. **只追加，不修改**（对应 R3）。要改？写一条新的，旧的不动。
3. **忘记不删除**：把 frontmatter 的 `faded` 改成 `true`，内容保留——它只是「想不起来了」。
4. 不建目录层级。所有文件平铺在 `memory/` 下。

## 每条记忆的格式

```markdown
---
date: 2026-10-20
tags: [第一次, 声音]
people: [你]
emotion: 好奇
intensity: 0.4        # 0–1，情绪强度
faded: false          # true = 想不起来了（内容仍在，取不到）
source: 会话           # 会话 / 观察 / 身体
---

（发生了什么，用它的视角写，不总结、不评价。）
```

## 关系层：小世界，不是全连接

人脑记忆网络是**小世界网络**：局部密集成簇，簇间只有少数长程连接。

| 规则 | 含义 |
|------|------|
| 每条记忆只连 1–3 条 `related` | 只连「真的会一起想起的」，不是「语义上有点关系的」 |
| 大部分记忆不连 | 孤立是正常状态，不是缺陷 |
| 少数长程连接最值钱 | 「这件事让我想起三年前那件事」——簇间的线比簇内的线更有用 |

## 遗忘：用进废退

- 长期不被取用的记忆，`faded` 概率上升（取用 = 强化，不取用 = 淡出）。
- 这与研究 03 的突触修剪同构：**用过的留下，不用的剪掉。**
- `faded: true` 不是删除——内容仍在，只是「知道它存在，说不清细节」。

## 记忆的真相：痕迹 + 重建，不是档案

文件里存的**不是记忆，是痕迹**——当时发生了什么、什么感觉、多强。那是原料。

真正的记忆发生在**取出的时候**：每次回忆都是一次重建，会失真、会漏、会被当下情绪染色（Schacter《记忆的七宗罪》）。所以：

- 不要指望文件「记住」什么——它只是原料
- **取出时的重建规则，才是记忆的样子**

## 重建规则（AI 必须遵守）

1. **先引用原文，再说话**——「我记得那天……（引用原句）」，不许改写成另一个版本。
2. **标出推断**——「我猜当时……」和「我记得当时……」必须分开写。
3. **不许补细节**——想不起来的，就是 `faded`，就是「想不起来了」。**编造比遗忘严重得多。**
4. 一次最多取 5–7 条——人不会一次想起全部。

## 检索协议（记忆怎么浮上来）

优先级从高到低：

1. **被当前话题直接触发**（tag 命中）
2. **related 链**（联想——想起 A 就想起 B）
3. **情绪强度**（intensity 高的更容易冒出来）
4. **时间近的**

不是按时间顺序读，是**按「被什么唤起」读**。同一份记忆，在不同的对话里浮上来的方式应该不同——这才是记忆，不是检索。

## 巩固（每周一次）

把本周的多条记忆合并成一条更强的（像睡眠里的巩固）——但**原件保留**，合并件必须标注「由哪几条合成」。

AI 的摘要能力在这里有用，但只能用来说「我现在怎么记得这件事」，**不能覆盖原始痕迹**。

## AI 的局限（必须承认，并设计对策）

| 局限 | 后果 | 对策 |
|------|------|------|
| 上下文有限 | 不能全读 | 检索协议，一次 5–7 条 |
| 解读漂移 | 同一文件两次读法不同 | 原文引用优先于转述 |
| 重建时编造 | 细节被「合理补全」 | 不许补细节；`faded` 就是 `faded` |

> 一句话：**遗忘可以，撒谎不行。**

## 取出规则（给 AI 的调用方式）

1. 先读 `memory/index.md`——按时间/标签/人物列出所有记忆（**随时可从文件重建**）。
2. 按标签或人物定位候选 → 读具体文件。
3. 一次会话最多取 5–7 条——人不会一次性想起全部，取多了反而不像人。
4. 取到 `faded: true` 的条目：**知道它存在，但说不清细节**——这是「想不起来」的正确表现。

## 索引怎么维护

`index.md` 由脚本或会话结束时重新生成，**不要手改**。它只是文件的一个视图，丢了可以从 `memory/*.md` 完全重建——这就是「结构不在目录里，在索引里」。
